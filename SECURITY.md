# Security Policy

## Authorized Use

Nayak The Hacker is intended for authorized security assessment and defensive testing.

Only scan systems that you own or have explicit permission to assess.

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately to the repository owner before publicly disclosing it.

Please include:

- A clear description of the issue
- Steps to reproduce
- Affected component or file
- Security impact
- Relevant logs or proof-of-concept evidence, where safe

Do not include real credentials, tokens, private keys, personal data, or other sensitive information in reports.

## Responsible Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.

Security testing against third-party systems without authorization is not permitted by this project's intended use.
